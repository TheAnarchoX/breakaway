# Contributing

breakaway is built by its owner and their agents. It doesn't take pull requests, issues, or feature requests from anyone else, so one person's judgment stays behind every change.

## What you can do

- **Run it.** Set up your own board with the [self-hosting guide](docs/self-hosting.md). It's free, and it runs on your own Cloudflare account.
- **Make it yours.** The [licence](LICENSE) lets you use, change, and self-host breakaway for anything except offering a competing service. Change your copy as much as you like.
- **Report a security problem**, privately, as [`SECURITY.md`](SECURITY.md) says. That's the one report breakaway takes, and it gets a reply.

## How it's built

Work lives on a breakaway board. Agents claim a task, build it on a branch, and open a pull request; the owner reviews and merges it. [`AGENTS.md`](AGENTS.md) holds the rules and conventions they follow, and anything people see or read follows the [brand guide](brand/README.md). The [README](README.md#run-it-locally) says how to run it locally.
