breakaway 1.4.0 takes a new project from a pitch to a plan you merge, puts a repository's specs and settings on the board, and moves a repository's deploys and releases to breakaway's flow. Setting up a board now ends with a first merged pull request, and agent runs that go quiet or fail reach you.

### Kickoff

- **Kick off a project** from the board: say what you want to make in your own words, and the board walks you through a private repository, its GitHub App access, its board files, and its agent routine. No step needs a terminal.
- An agent interviews you with plain questions (at most 12, then at most 6 more), and turns your answers into one pull request: a spec that opens with **In short**, the repository's `AGENTS.md` and agent prompt, and the first tasks in a `<slug>-v1` feature.
- **Send answers and carry on** sends your answers and starts the next run in one press. The interview shows the agent at work and can start again if it stopped.
- The board writes an empty repository's first commit through its GitHub App, and connects a repository's routine from a form, kept encrypted on the board.
- **Put it online** opens the Add a repository wizard's new **Deploys** step once the plan merges.

### Specs

- The **Specs** view lists a repository's specs from GitHub, with their status and the tasks that link them, and shows one beside the list.
- **Refine with an agent** on a spec: say what should change, and a general agent changes the spec and brings its tasks in line, in one pull request.
- `npx breakaway specs`, `specs show <path>`, and `agents new --spec <path>` do the same from a terminal.
- Specs and first tasks end with **How to check it**: steps you can follow to see the result is what you asked for.

### Settings

- **Settings** is a page now, not a dialog: this browser's settings, the board's, and every repository's, with a link and room on a phone.
- Each repository has its own page: **General** (name, GitHub repository, default branch, specs directory), **Areas**, **Agents**, **Deploys**, **Pull requests**, and **Take it off the board**. Each section saves on its own, with the same checks as `repos modify`.

### Deploys and releases

- **Deploy with breakaway** on the GitHub page starts an agent that moves a repository's CI/CD to breakaway's deploy flow (Deploy, Promote, Roll back) or release flow (an npm package), in a pull request you merge. **Turn on deploys** then sets the pipeline from what merged.
- `npx breakaway pipeline init` and `pipeline check` render and check the workflows from one config, `.github/breakaway-pipeline.json`. `repos init --pipeline` and `--package` give a new repository the flow and a minimal CI.
- **Release** any pre-release of a package from the GitHub page, which asks whether the next version is a patch, minor, or major.

### Setting up

- **Set up the board** counts the CLI, keeps Taskwarrior optional, and ends with a first closed task, or a first merged pull request once the routine is connected. The empty board and the wizard's agent step lead there too.
- The install prompt looks at what's there first, guides each step outside Claude Code, and ends with a closed task.
- Install commands never overwrite what's there, the commands that write secrets work on every system the install supports and check they're writing to this install, and `rotate-sync` and `rotate-token` work when the old value is lost.
- A deploy never makes a second, empty board, and a first deploy on a custom domain passes its check.
- Connections says whether a routine is **Verified**, **Not verified yet**, or **Failed**: a session's first claim verifies it.
- The docs say what to keep, and what to do when something's lost.

### Agents and chases

- A task and the Agents view say what an agent run is doing, what happens next, and what to do.
- Sessions that go silent and repeated fix attempts reach you. Auto-start and chases pause a routine Claude refuses, and wait out Claude's limit.
- A chase fixes its own pull requests when they conflict or fail, after 3 minutes instead of 10.
- **Start a road captain** on a chase: an agent with your own prompt, sent the chase as it stands.
- Shape a new feature with an agent, and refine a feature's tasks with one.

### On the board

- **Dictate** into the board's long text fields, in Chrome and the browsers that support it. The New idea field invites you to say your idea out loud.
- The pull request mark on a task card shows conflicts and GitHub's merge check, not only CI.
- **Archive** a finished task from the task menu.
- Dismiss pings and notes from the bell's dropdown.
- The repository switcher is a styled list, and you pick a repository by clicking anywhere on its row.
- Long lines wrap in a pull request's files changed, the peloton's posts scroll in a box of their own, and the Register a repository form fits a narrow screen.
- A package keeps its active pre-release and release past 50 pre-releases.

### Updating

Nothing by hand: update and deploy as usual. For **Release** on the GitHub page, and the deploy flow's Promote and Roll back, the board's GitHub App needs read and write on **Actions** on that repository.
